# Review logs

> **Review records, kept as evidence of the independent-review process** that [AI_USE_DECLARATION.md](../../AI_USE_DECLARATION.md) cites as verification of AI-assisted work. Each log is a point-in-time record: its findings, fixes and "not yet run" statements describe the state on its date. Current status of the open review gates is in [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md) and [README.md](../../README.md#known-limitations). Where a log and the evidence differ, the evidence is authoritative.
